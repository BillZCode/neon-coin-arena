Info Koneksi & Instalasi:
• Endpoint AWS WebSocket utama: wss://<api-id>.execute-api.us-east-1.amazonaws.com/dev
• Android: Setelah mengunduh NeonCoinArena-Android.apk, buka file dan izinkan instalasi dari sumber ini (Install unknown apps).
• Windows: Jika muncul peringatan Windows SmartScreen untuk file .exe baru, klik More info → Run anyway.
• Linux / macOS: Beri izin eksekusi terlebih dahulu dengan chmod +x NeonCoinArena-* lalu jalankan file tersebut.
• Ganti Server Kapan Saja: Buka menu ⚙ Pengaturan Server (Opsional) di lobi game untuk memilih antara AWS WebSocket Service, VPS 24/7, atau URL WebSocket kustom.
